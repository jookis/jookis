### Hi, I'm jookis

I believe AI should write more of our code and humans should still decide what ships.
I build small, self-hosted tools that run on your own hardware, independently.

**What I'm working on**

- **[nimblegate](https://github.com/nimblegate/nimblegate)** - a self-hosted git gateway
  between your AI coding agents and your real repo. It checks every push against your
  rules, catches leaked keys and the shortcuts agents take to look finished, and records
  every decision. [Website](https://nimblegate.com) · [Live demo](https://demo.nimblegate.com)
- **[nimblecube](https://github.com/jookis/nimblecube)** - an integer-only similarity
  memory for microcontrollers, in kilobytes of flash.
