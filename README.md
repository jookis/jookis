Self-hosted software tools and independent research in combinatorics and embedded computing.

**Software**

- **[nimblegate](https://github.com/nimblegate/nimblegate)**: a self-hosted git gateway between AI coding agents
  and the repository they work on. It checks every push against configurable rules, catches leaked keys and
  incomplete work, and records every decision. [Website](https://nimblegate.com) ·
  [Live demo](https://demo.nimblegate.com)
- **[nimblecube](https://github.com/jookis/nimblecube)**: an integer-only similarity memory for microcontrollers,
  in kilobytes of flash.

**Research**

- **n-queens research**: the preprint "The fewest and the most toroidal conflicts of an n-queens solution"
  (Jouko Kines, 2026; [doi:10.5281/zenodo.23755751](https://doi.org/10.5281/zenodo.23755751)), whose main theorems are verified in Lean 4; the code,
  data and Lean proofs are in the Zenodo record. Notes and interactive pages:
  [pieceofdiy.com/queens](https://pieceofdiy.com/queens/). The [queens-notes](https://github.com/jookis/queens-notes)
  repository points to both.
